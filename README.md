### About

I studied Humanoid Robotics at BHT Berlin and have been doing embedded work for a few years, mostly C on the RP2040.

At work I wrote an Active Object / HSM framework on top of FreeRTOS. It started on a stepper board and a gateway board and is now in production. For my bachelor's thesis I added CANopen (CiA 402) to it.

These days I'm drifting more towards automation and commissioning, the part where the hardware leaves the desk.
